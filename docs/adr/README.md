# Architecture Decision Records

Ten katalog przechowuje ADR dla decyzji implementacyjnych miniPORTAL 1.0.

Format nazwy:

```text
0001-short-decision-title.md
```

Minimalny szablon:

```markdown
# ADR-0001: Tytuł

Status: Proposed | Accepted | Superseded | Rejected
Date: YYYY-MM-DD

## Context

## Constraints

## Considered options

## Decision

## Consequences

## Revisit trigger
```

ADR zapisuje **dlaczego** wybrano rozwiązanie. Dokumenty architektury opisują **jak system ma działać po decyzji**. Nie należy używać ADR jako zamiennika aktualizacji głównej dokumentacji.
